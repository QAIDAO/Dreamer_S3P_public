# 量子科研智能体从黑客松实践到光响应分子判别

本仓库是同名论文的配套研究仓库，提供与论文方法和光响应分子案例对应的代码、数据、科研技能及运行记录，支持研究方法理解、流程组织方案验证与后续应用研究。

## 研究目标与技术路径

量子计算服务于分子与材料研究，需要将问题构建、程序设计、设备执行与经典分析衔接为连续的科研流程。智能体借助任务规划、工具调用和执行反馈，为组织这些环节提供了可能。现有研究多从单个系统的实现经验出发讨论相关功能，跨实现的功能归纳有助于明确智能体在量子科研流程中应承担的职责。

论文围绕这一问题开展三方面工作：

1. **从黑客松实践归纳功能要求。** 以LoomQ 2026黑客松的58份团队提交为依据，比较跨平台程序执行、智能体辅助实验以及经典与量子混合执行的实现步骤，归纳任务规划、平台接入、独立检查、状态维护、经典与量子数据衔接、结果解释与交付六类功能。
2. **在晓梦智能体中组织实现。** 通过专业技能和工具明确步骤依赖、输入输出约定与检查规则，协调CPU、GPU和QPU，并以对象编号、任务状态和阶段记录保持各环节的数据关联。
3. **通过真实量子设备案例检验可行性。** 以光响应分子判别为案例，将分子生成、结构筛选、量子特征采集与经典分类组织为端到端流程，展示真实量子设备如何接入可执行、可追溯的科研任务。

## 光响应分子案例

案例由Dreamer S3P科研技能组织，主要计算环节为：

**分子生成（GPU） → 结构筛选与表征（CPU） → 量子特征采集（NMR QPU） → 分类与排序（CPU）**

条件GPT-2根据结构描述生成20条SMILES，其中7条结构有效，5个候选满足QED与SA筛选条件。候选经指纹、标准化及三维PCA变换构造线路输入，由核磁共振量子设备采集8维测量特征，再交给经典支持向量机完成分类排序。

各阶段通过分子编号关联结构、线路输入、量子任务与分类结果。输入输出检查、状态记录和局部重跑机制贯穿执行过程，使专业工具与异构计算节点能够围绕同一研究任务协同工作。

## 仓库如何支持论文研究

仓库围绕论文的功能组织方案和分子案例提供以下材料：

| 配套材料 | 内容与研究用途 |
|---|---|
| [科研流程实现](src/s3p_repro/)与[方法配置](configs/paper.json) | 提供分子筛选、指纹与PCA、量子特征、分类及执行记录的实现，用于核对方法参数和阶段间的数据衔接。 |
| [生成模型训练与生成代码](src/s3p_repro/training.py)、[生成接口](src/s3p_repro/generation.py)及[ChEBI-20数据](data/generation/) | 支持研究从分子文字描述到SMILES的条件生成方法，并按论文配置开展训练和生成。 |
| [分类数据](data/classification/)与[案例数据](data/case/) | 提供648个训练样本、162个测试样本的固定划分，以及20条案例输出和5个入选候选，支持核对结构、筛选指标与候选记录。 |
| [科研技能](.agents/skills/dreamer-s3p-paper/SKILL.md)与[智能体角色提示](agent.md) | 将六类功能落实为任务规划、工具调用、程序检查、状态维护和结果交付的执行要求，支持在通用智能体中组织科研流程。 |
| [论文结果与运行记录](data/reference/) | 保存论文报告值、三次模拟补充评估结果和脱敏案例执行事件，供查阅、对照与分析。 |
| [程序测试](tests/)与[验证记录](docs/validation.md) | 支持检查特征计算、数据划分、输入输出、缓存与状态处理，以及训练代码中的损失掩码等具体实现。 |

这些材料可用于核对论文方法与案例记录，运行计算流程并检查其数据关联和阶段产物，也可作为扩展生成模型、分类方法或量子后端的研究基础。论文各节与代码、数据的具体对应关系见[论文与仓库对应说明](docs/paper_mapping.md)。

## 智能体与科研技能

论文原案例由晓梦组织执行，使用DeepSeek完成需求理解、规划与工具调用。晓梦为商业桌面科研智能体，其内核源码未公开。本仓库提供独立的科研流程参考实现，并将流程整理为可由Codex等通用智能体使用的skill。

[agent.md](agent.md)给出科研智能体的功能要求与角色提示，[科研技能](.agents/skills/dreamer-s3p-paper/SKILL.md)约定执行步骤、工具接口和交付产物，[AGENTS.md](AGENTS.md)提供仓库执行入口。例如，可以向智能体提出：

> 使用 $dreamer-s3p-paper，根据论文的方法配置组织光响应分子判别流程。先说明任务计划与计算分工，再执行数据检查、结构筛选、量子特征模拟和分类，交付候选排序及阶段运行记录。

## 阅读与运行入口

- [论文与代码对应关系](docs/paper_mapping.md)：了解论文方法、案例和仓库材料的对应位置。
- [数据说明](docs/data.md)：查看数据来源、标签定义、固定划分及案例记录。
- [训练说明](docs/training.md)：开展条件GPT-2训练与分子生成。
- [设备说明](docs/hardware.md)：配置NMR设备接口与执行后端。
- [验证记录](docs/validation.md)：查看已执行的程序检查及检查命令。

基础计算流程可在CPU环境中运行。参考验证环境为Python 3.13，固定依赖版本见[requirements.txt](requirements.txt)。在独立Python环境中，从仓库根目录执行：

```bash
python -m pip install -e .
python scripts/s3p.py inspect-data
python scripts/s3p.py replay-case --output outputs/replay
python scripts/s3p.py pipeline --output outputs/simulator
```

以上入口分别用于检查分类数据、读取案例记录并重算结构有效性与QED/SA，以及运行新的CPU模拟流程。新运行的预测、指标与阶段产物保存在`outputs/`，论文参考记录保存在`data/reference/`。训练生成与真实设备执行的具体设置见相应说明文档。
