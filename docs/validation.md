# 参考实现验证

本仓库在Python 3.13.5、NumPy 2.4.4、scikit-learn 1.8.0、RDKit 2026.3.1、PyTorch 2.11.0和Transformers 5.5.0环境下完成以下检查。

- 15项程序测试通过：线路门顺序与位序、概率内积核的解析等价性、无效概率拦截、固定骨架划分、预处理不读取测试集统计量、案例回放、缓存复用、设备状态不明时停止重试、训练掩码、反向传播、模型保存/加载与有界生成。
- 648/162分类数据的标签数量、芳基偶氮结构统计及骨架交集与论文一致；9组补充混淆矩阵与准确率一致。
- 20条案例输出重新解析后为7条有效结构，5条满足筛选条件；表4的结构、QED和SA一致。
- 默认CPU模拟流程完成训练、162例测试及5候选排序，产物标记为新的模拟运行。
- 训练代码以16对样本和2个优化步进行小型GPT-2执行检查；没有重新进行完整10轮正式训练，没有把小型检查结果视为论文生成模型。
- 本次程序验证没有访问真实量子设备；设备worker的实际可用性取决于使用者的设备、SDK及授权。
- 发布文件集合通过脱敏扫描；不包含本机路径、私人账号、密钥、设备连接信息、商业应用内核及运行环境。

复查命令：

```bash
python -m pip install -e ".[train,test]"
python -m pytest -q
python scripts/verify_data.py
python scripts/check_release.py
```

以上是参考实现的代码验证，不替代论文中原有研究评估。新运行的逐样本预测和指标在`outputs/`下保存，历史参考数值不被覆盖。
